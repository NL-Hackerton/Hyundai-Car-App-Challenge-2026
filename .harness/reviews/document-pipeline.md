### 1. [P1] 출력 경로가 원본·원고를 가리키는 링크인지 확인한 뒤 저장하십시오

- **결함·발생 조건·영향:** 출력 DOCX를 `document.save(target)`으로 직접 덮어쓰지만 출력 파일과 상위 디렉터리의 실제 경로를 검사하지 않는다. 따라서 `submission/application-review.docx`가 공식 원본을 가리키는 심볼릭 링크인 상태에서 `--replace`하면, 시작 시 원본 해시 검사를 통과한 뒤 원본 자체에 본문을 덮어쓴다. 원고를 가리키는 링크에서도 같은 문제가 발생한다. 저장소 밖을 가리키는 출력 디렉터리 역시 차단하지 않는다.

### 2. [P2] 괄호가 포함된 링크 주소를 끝까지 보존하십시오
