## 점수를 올린 보강

- 에뮬레이터 실측 4~7차: SOC 구독 간격, 잔량 기반 전력 추정과 스파이크, 도착 예상 SOC·경로 소비 전력량, 충전 경유지 삽입 경계(직행 도착 약 10%, 목적지 4곳), 경유지 최대 출력·충전기 수, `onDrivingInfo` 수신 조건, 화면 제한 전환, 충전 스위치 상태의 한계. 원 로그 발췌를 첨부 파일로 붙였다.
- 규칙 5 재설계: 부족분 ΔE를 여기서 채우는 시간 ΔE÷P와 후보에서 채우는 시간 ΔE÷Pc+s 비교, Pc는 SOC 구간별 기록 또는 0.7×C÷T.
- 사업성: MAU·재사용률 점화식과 민감도(표 9), 운영비 F와 손익분기 사이트 수, G×t와 t·f·동의율 민감도, 단계별 진행·중단 기준.
- 데이터 처리: 기본 기능은 차량 안에서만 판정하고, 외부 통신은 사용자가 켜는 선택 기능 세 가지로 한정.
